# Letter-web
Page 1

A sealed envelope fades in slowly.
Click the envelope and the flap opens, then a torn-paper note appears with your custom quote.
A "scroll down" hint fades in after the note shows up.

Page 2 
A torn-paper note slowly appears and asks the big question.
Two buttons show up below it: Yes and No.
The No button runs away whenever the mouse gets close (or when it's touched on mobile), so it can't be clicked.
Clicking Yes slowly reveals a full-screen message with your image and floating hearts.

Getting started
Clone or download this repo.
Open index.html in your browser.
That's it.
